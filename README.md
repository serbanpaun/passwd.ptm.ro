# Strong Password Generator
A script to gernerate secure passwords of minimum 16 characters, including `lowercase`, `UPPERCASE`, `symb0|s` and `numb3r5`.
An optional `Limited` checkbox can be checked, in order to use a limited set of symbols (restricted by some websites who don't care about security).

You may see it in action at [https://passwd.ptm.ro/](https://passwd.ptm.ro/).
